# 円錐管モード（並列慣性ポートによる円錐近似）— 設計書

初版 2026-10-13

親設計書: [`2026-09-03-reed-waveguide-synth-design.md`](./2026-09-03-reed-waveguide-synth-design.md)（以下「親設計書」）。
本書に書かれていないことは親設計書に従う。食い違ったら本書が正（円錐管に関する部分のみ）。

## 1. 目的

既存の円筒閉管（クラリネット）と同じ自励振動部のまま、**管だけを円錐（サックス的）に切り替えて
聴き比べ・見比べられる**ようにする。比較の見どころ:

| | 円筒 | 円錐 |
|---|---|---|
| 共鳴列 | 奇数倍音（f, 3f, 5f…） | ほぼ全倍音（f, ≈2f, ≈3f…、高次ほど高くずれる） |
| 裏返り | 12度 | オクターブ |
| f0 | `c/(4L)` | `tan(kL) = −kX_apex` の第1根（≈ `c/2(L+X_apex)`） |
| 管内の圧力分布 | 一様な定在波 | 狭い側ほど振幅が大きい |

既存の円筒モードの挙動は**一切変えない**（ビット一致で保護する。§6）。

### 非目標

本物の円錐導波路（球面波・円錐接合の散乱）、トーンホール、マウスピース容積の別モデル化、
円錐用の音色作り込み。

## 2. 手法と根拠

### 2.1 出典

US5438156A（ヤマハ、増田・國本、1991年優先、ページ表示上は権利消滅）。
円錐管の入力インピーダンスを「喉部（欠けた頂点）」と「本体」の並列に分解し、
それぞれを円筒導波路で近似する。特許は喉部側の円筒を「できるだけ短く、遅延1段が望ましい」としている。

### 2.2 本書の採用形（案A: 慣性ポート）

切頭円錐（頂点から `X_apex` の位置で切った長さ L の円錐）の入力アドミタンスは

```
Y_cone = (S/ρc) · [ −j·cot(kL)  +  1/(j·k·X_apex) ]
           本体（開管端の円筒 L）    頂点の慣性 M = ρ·X_apex/S
```

第2項は**近似ではなく厳密**（`ψ = r·p` が1次元波動方程式を満たすことから出る）。
特許の「短い円筒」はこの慣性の近似で、その極限が波動デジタルフィルタのインダクタ
（1サンプル遅延・反射 −1）になる。本書はこれを採用する。

- 慣性ポートの反射: `p2⁻[n] = −p2⁺[n−1]`
- ポートインピーダンス（W1 の特性インピーダンスで正規化）: `R2 = 2·X_apex·fs_internal / c`、
  重み `Y2 = 1/R2 = c / (2·X_apex·fs_internal)`
- 低域で `R2·tan(ωT/2) ≈ ωX_apex/c` となり慣性 `jkX_apex` に一致（双一次変換）

**検算済み**（2026-10-13、L=0.6m, X_apex=0.06m）:

```
       厳密根    WDF@48k   倍音比（厳密）
n=1    260.5     260.5     1.000
n=2    524.1     524.1     2.012
n=3    792.3     792.3     3.042
n=5   1340.5    1340.4     5.147
L=0.2m では n=2 が 2.112、n=3 が 3.298（高音ほど倍音がずれる。実物のサックスと同種）
```

WDF近似は厳密根と0.1%以内。

## 3. DSP コア

### 3.1 接合部の一般化（`ReedTubeModel`）

命名注意: 親設計書の `X = max(x,0)` はリード開口。頂点欠損長は本書では `X_apex`、コードでは `apexLength`。

ポート:
- ポート1 = 既存の W1（遅延線・ベル反射・wallLoss）。重み `Y1 = 1`
- ポート2 = 慣性ポート（円錐モードのみ）。重み `Y2`（§2.2）

1サンプルの手順（親設計書 §4.4 からの差分のみ）:

```
1.  p1⁻ ← W1 から読む（既存）
1'. p2⁻ = −p2⁺_prev                        （円錐のみ）
    Ysum   = Y1 + Y2
    pm_eff = (Y1·p1⁻ + Y2·p2⁻) / Ysum
    ζ_eff  = ζ / Ysum
2-3. b = γ − 2·pm_eff、ũ_eff = solveBernoulli(ζ_eff, X, b)
4.  ũ_eff += noise·(|ũ_eff| + 0.02)·rand   （既存と同じ式）
5.  p̃ = ũ_eff + 2·pm_eff
    p1⁺ = p̃ − p1⁻（W1 へ書く。既存）、p2⁺_prev = p̃ − p2⁻（円錐のみ）
7.  Δp̃ = γ − p̃ でリードを進める（既存）
```

導出: 接合部で圧力が共通（`p̃ = p_i⁺ + p_i⁻`）、総流量 `ũ = Σ Y_i (p_i⁺ − p_i⁻)` から
`p̃ = ũ/Ysum + 2·pm_eff`。`ũ_eff = ũ/Ysum` と置くと Bernoulli 式は `ζ_eff` で同じ二次方程式になる。

**円筒モードは既存コードと同じ演算順を通す**（`Y2` の分岐に入らない）。§6 のゴールデン値で検証。

**単純化**: 乱流ノイズは `ũ_eff` に足すので、円錐では総流量換算のノイズ量が `Ysum` 倍になる。
`noise` スライダーの意味が形状で少し変わるが、比較の妨げにはならないので受容する。

**可視化用の流量**: スナップショットの `u` には総流量 `ũ = Ysum·ũ_eff` を記録する
（パネル2の準静的特性曲線 `ζ·max(1−Δp̃,0)·sign·√|Δp̃|` と整合させるため。円筒では `Ysum=1` で既存と同じ）。

### 3.2 状態・切替・ガード

- 慣性ポートの状態は `p2⁺_prev` の1スカラー
- `setBoreType('cylinder'|'cone')`: フラグ切替、`p2⁺_prev = 0`、out[0] を5msフェード（既存の `_fadeRemaining` を再利用）
- `setOversample`: `Y2` は毎ブロック `fsInternal` から再計算するので状態変換は不要
- 発散ガード: `p2⁺_prev` もゼロリセット
- `apexLength` は k-rate。`applyKRateParams` で受ける

### 3.3 範囲

`apexLength` 0.005〜0.15m、既定 0.06m。下限で `Y2 = 343/(2·0.005·48000) ≈ 0.71`（2×で0.36）なので数値的に安全。

## 4. 音高

### 4.1 純関数（`src/midi.js`）

- `coneF1(L, X_apex)`: `tan(kL) = −kX_apex` の第1根の周波数。`kL ∈ (π/2, π)` を二分法で解く
  （`X_apex→0` で `c/(2L)` に収束）
- `noteToLength(note, bore='cylinder', X_apex=0.06)`:
  - cylinder: 既存式 `c/(4f)`（既存の呼び出し `noteToLength(note)` はそのまま動く）
  - cone: 厳密な逆関数 `L = (π − atan(kX_apex)) / k`、`k = 2πf/c`
  - どちらも `L ∈ [0.15, 1.2]` にクランプ
- 円錐・X_apex=0.06 のとき f0 ≈ 136〜817Hz（アルトサックスの音域にほぼ一致）

### 4.2 MIDI コントローラ

- `createMidiController` の opts に `getBoreConfig: () => ({ bore, apexLength })` を追加し、`retune` で使う
- `retuneCurrent()` を追加: 形状・`apexLength` が変わったとき鳴っているノートを再チューニング

## 5. UI・可視化

### 5.1 UI

- 「管」グループに **管の形状** セレクタ（円筒 / 円錐、既定 円筒）
- **頂点欠損長 X（円錐のみ）** スライダー（0.005〜0.15m、既定0.06m）。円筒時は無効化表示
- 形状切替は port メッセージ `setBoreType`、`apexLength` は AudioParam

### 5.2 裏返りインジケータ

- 管f0: 円筒 `c/(4L)`、円錐 `coneF1(L, X_apex)`
- 表示文言: 円筒「比≈3で第2レジスタ」、円錐「比≈2で第2レジスタ」

### 5.3 パネル3（管内の定在波）

円錐内の圧力は `p(r) = ψ(r)/r`（r は頂点からの距離）で、W1 の波は ψ に対応する。
円錐モードでは `combineStandingWave` の結果に `X_apex / (X_apex + z_m)` を掛けて描く
（`z_m = z·L/nTube`、z=0 がリード端）。純関数 `coneScaleStandingWave(combined, X_apex, L)` として `src/scope.js` に置く。

パネル1・2・4は変更なし。
